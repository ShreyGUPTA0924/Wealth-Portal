This is the WealthWise web client — a [Next.js](https://nextjs.org) app (App Router, TypeScript, Tailwind CSS 4).

See the [root README](../README.md) for the full project overview and architecture.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser. Set `NEXT_PUBLIC_API_URL` in `.env.local` to point at the Express API (see root README).

## Deployment

Deployed on [Render](https://render.com/) alongside the API and AI service — see `render.yaml` in the project root.
